# ccs-mojo
A Mojo implementation of the NGA GEOTRANS Coordinate Conversion Service (CCS).
Provides coordinate transformations between 38+ coordinate systems including UTM, MGRS,
UPS, and various map projections. Compatible with the existing Java GUI via JNI interface.

## Reference Implementation

This repository includes the official GEOTRANS v3.7 implementation in the `geotrans/` directory.
The official implementation is a product of the National
Geospatial-Intelligence Agency (NGA) and U.S. Army Engineering Research and Development Center.

For license information regarding the official GEOTRANS implementation, please refer to
`geotrans/GEOTRANS3/docs/MSP_Geotrans_Terms_Of_Use.txt`.
